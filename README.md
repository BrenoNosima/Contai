# Breno Finance AI Backend
Arquitetura FastAPI + SQLAlchemy + LangChain + SQLite.

Sistema financeiro pessoal utilizando:

- FastAPI
- SQLite
- SQLAlchemy
- LangChain
- Gemini
- React (futuro)

## Funcionalidades

- Controle de receitas
- Controle de despesas
- Gastos fixos
- Metas financeiras
- Dashboard
- IA para registro automático

## Executar

```bash
pip install -r requirements.txt

python -m uvicorn app.main:app --reload
