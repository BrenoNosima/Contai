# Logotipo da Contaí

Coloque o logotipo principal neste diretório com o nome exato `contai-logo.png`.

- Use PNG com fundo transparente e versão horizontal.
- Prefira largura mínima de 480 px para telas de alta densidade.
- Não estique, recorte, aplique sombra ou altere as cores.

O site usa `/brand/contai-logo.png`. Enquanto o arquivo não existir, a marca
textual de reserva será exibida automaticamente.
